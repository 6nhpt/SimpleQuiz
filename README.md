# SimpleQuiz（列挙クイズ）

「アメリカ50州を全部言えるか」系の列挙クイズ。スマホのブラウザで遊ぶ前提。
Python 3 の標準ライブラリだけで動く（追加インストール不要）。

公開版（読み取り専用）: https://6nhpt.github.io/SimpleQuiz/

## 起動

```
start.bat            （または  python server.py 8080）
```

スマホから `http://<このPCのTailscale IP または LAN IP>:8080/` へ。
ホーム画面に追加するとアプリっぽく使える。手元のサーバー版ではクイズの追加・編集ができる。

## 公開（GitHub Pages）

`main` に push すると GitHub Actions が `build.py` を実行し、`dist/` を Pages に公開する。
公開版は読み取り専用（追加・編集ボタンは出ない）。

- 手元のサーバーで追加・編集 → `data/quizzes/` の変更を commit して push
- または `seed/` に txt を追加して push（GitHub の Web 画面からでも可。txt の先頭に `@title` などのヘッダを書く。既存の seed を参照）
- `python build.py` で公開版を手元に書き出して確認できる

## 構成

```
server.py            静的配信 + REST API（/api/quizzes）
build.py             公開用の静的サイトを dist/ に書き出す
public/              画面（素のHTML/JS/CSS、ビルド不要）
  app.js             画面（ホーム / 回答 / 一覧 / 編集）
  matcher.js         表記ゆれ吸収・判定ロジック
data/quizzes/*.json  クイズ本体（バックアップはこのフォルダをコピー）
seed/*.txt           初期データ。起動時に未取り込みのものだけ data に入る
```

回答の進捗はブラウザ（localStorage）に保存。端末ごとに別。

## クイズの書き方（編集画面）

```
名前 | 別解 | 別解 # メモ
```

- 漢字の項目には読みがなを別解として書く（`新宿区 | しんじゅく`）
- カタカナの項目はひらがなでも自動で正解になる
- 自動で吸収: 全角/半角、カタカナ/ひらがな、ヴァ↔バ、小書き文字（ウェ↔ウエ）、長音・中黒・空白の有無
- 「無視する接尾辞」に `州,しゅう` などを書くと、付けても付けなくても正解
- 「1文字違いまで許容」: 5文字以上の答えで、編集距離1の候補が1つに絞れるときだけ正解（ペンシルバニヤ → ペンシルベニア）
- `#` 以降のメモは回答画面の「ヒント表示」と一覧画面で表示される
- `## 区分名` の行以降の項目はその区分にまとまり、区分ごとに小計が出る
- 行頭に `*` を付けるとシークレット（総数に数えず、答えると+1して金色で表示。一覧画面では折りたたみ。ギブアップしても明かさない）
  - 区分の中身が全部シークレットなら「隠し区分」になり、1個見つけた時点で区分ごと空き枠付きで現れる（例: 元素の拡張周期表）
- 行頭に `?` を付けると判定のみ（答えるとメモを表示するが、正解には数えない。例: エカホウ素）

## 初期データを入れ直したいとき

- `seed/` に新しい txt を置いて再起動すると、それだけ取り込まれる（取り込み済みは `data/seeded.json` に記録）
- 既存のクイズを seed から作り直したいときは、`data/quizzes/` の該当JSONを消し、`data/seeded.json` からそのIDを消して再起動
